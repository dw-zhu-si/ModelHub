# 本机原生功能威胁模型

## 信任边界与资产

- HTTP、MCP 与 A2A 请求及 ACP 客户端输入均视为不可信；唯一 HTTP 监听地址保持 `127.0.0.1:11435`，ACP 使用换行分隔 JSON-RPC stdio。
- 网关令牌和供应商 API Key 是最高敏感资产，只存在 Keychain 和必要的短期内存中。
- 提示词、工具参数、模型输出与上传内容不得进入分析、Widget、备份或普通日志。
- 本机配置、价格元数据、健康记录和聚合用量属于可备份数据，但不等于凭证。

## 主要滥用场景与控制

| 风险 | 控制 |
|---|---|
| 本地网页通过 DNS rebinding 调用管理面 | 仅回环监听、Bearer 鉴权、拒绝非空且非本机 Origin |
| 高频请求造成费用或资源失控 | 每分钟请求限制、并发限制、最大回退次数、指数退避、预算硬限制可选 |
| 故障供应商形成重试风暴 | 连续失败熔断、冷却期、只向下一可用目标回退 |
| 分析或备份泄漏内容与凭证 | 字段白名单、Keychain 永不导出、不记录请求/响应正文 |
| 恶意备份覆盖配置或注入超大数据 | 10 MiB 上限、版本验证、字段解码、导入前自动回滚副本 |
| Agent 协议获得过度权限 | 独立 Agent 令牌、只读工具、ACP 不调用模型、无文件/进程/网络写工具 |
| 流式响应无限占用内存或断开后继续计费 | HTTP chunked 增量转发、客户端断开取消上游读取、仅保留最多 4 MiB 临时用量解析缓冲且不落盘 |
| 上下文优化破坏工具参数或代码 | 默认关闭；只处理文本内容；跳过代码围栏、工具调用和非文本内容 |
| 未知价格产生误导 | 未配置价格时费用保持“未知”，不按 0 美元宣称 |

## 明确排除

- 不读取或导入其他应用凭证。
- 不监听局域网或公网，不创建隧道或云中继。
- 不修改系统代理、不实施 MITM、不安装根证书。
- 不下载或执行第三方压缩器、代理或辅助二进制。
