# 本机原生功能威胁模型

## 信任边界与资产

- HTTP、MCP 与 A2A 请求及 ACP 客户端输入均视为不可信；唯一 HTTP 监听地址保持 `127.0.0.1:11435`，ACP 使用换行分隔 JSON-RPC stdio。
- 网关令牌和供应商 API Key 是最高敏感资产，只存在 Keychain 和必要的短期内存中。
- 提示词、工具参数、模型输出与上传内容不得进入分析、Widget、备份或普通日志。
- 本机配置、价格元数据、健康记录、最多 50 条的结构化健康活动和聚合用量属于可备份数据，但不等于凭证；健康活动只保存计数、时间、关联 ID 和供应商 UUID，不保存 URL、请求/响应或原始上游错误。
- 模型名录、CSV、供应商价格和 ECB 参考汇率属于不可信外部输入；解析前必须执行大小、格式、来源与数值边界检查。
- 代理订阅 URL、订阅正文和节点名称属于不可信高敏感输入；URL 只进入 Keychain，正文只在 0700 临时目录内以 0600 文件短期物化。

## 主要滥用场景与控制

| 风险 | 控制 |
|---|---|
| 本地网页通过 DNS rebinding 调用管理面 | 仅回环监听、Bearer 鉴权、拒绝非空且非本机 Origin |
| 高频请求造成费用或资源失控 | 每分钟请求限制、并发限制、最大回退次数、指数退避、预算硬限制可选 |
| 故障供应商形成重试风暴 | 连续失败熔断、冷却期、只向下一可用目标回退 |
| 分析或备份泄漏内容与凭证 | 字段白名单、Keychain 永不导出、不记录请求/响应正文 |
| 恶意备份覆盖配置或注入超大数据 | 10 MiB 上限、版本验证、字段解码、导入前自动回滚副本 |
| Agent 协议获得过度权限 | 独立 Agent 令牌、只读工具、ACP 不调用模型、无文件/进程/网络写工具 |
| 流式响应无限占用内存或断开后继续计费 | HTTP chunked 增量转发、客户端断开取消上游读取、仅保留最多 4 MiB 临时用量解析缓冲且不落盘 |
| 上下文优化破坏工具参数或代码 | 默认关闭；只处理文本内容；跳过代码围栏、工具调用和非文本内容 |
| 未知价格或默认价产生误导 | 只对精确模型 ID 使用已核对的内置上游公开参考价，来源显式标注“非当前渠道结算价”；供应商机器价、CSV 和手工价优先；无法可靠匹配时保持“未知”，不按 0 美元宣称 |
| 恶意或错误 CSV 消耗内存、注入凭证 URL | 仅接受 CSV；文件上限 8 MiB、最多 10,000 行、模型名长度与控制字符校验；HTTP(S) 端点拒绝用户信息和敏感查询参数；导入前预览 |
| 模型目录重定向或伪造响应导致凭证外泄、资源耗尽 | 只使用用户保存的完整 URL或严格主机注册表；拒绝重定向、跨源最终 URL、HTTP 公网、URL 凭证和敏感查询；响应流式读取且有 8 MiB 上限 |
| 自动价格更新造成隐式上游负载或错误费用 | 默认每日本机时间 00:00、逐供应商串行、20 秒超时；只解析明确单位的机器可读价格；内置参考价随版本发布而不在运行时抓网页；失败保留现有价格 |
| 展示币种只换符号、汇率过期或来源被替换 | 存储金额始终为 USD；启动补更新并每 6 小时检查 ECB 最新发布数据，失败 30 分钟后重试且保留上次成功值；按固定 ECB HTTPS 地址读取、最终主机校验、512 KiB 上限、数值有限且大于 0；界面显示币种、来源、生效日、获取时间和最近失败 |
| 内存缓存跨密钥泄漏或无限增长 | 默认关闭；缓存键包含访问范围摘要；只缓存完全相同的非流式成功请求；TTL、过期、条目数、总字节数和 LRU 淘汰形成硬上限；不落盘 |
| 虚拟密钥泄漏或越权 | 原始令牌只显示一次，配置只保存 SHA-256 摘要；固定时序比较；工作区模型、速率、预算、地区与到期策略按失败关闭执行 |
| 订阅 URL 令牌进入配置、显示名称、备份或日志 | URL 仅存 Keychain；配置只保留来源域名；界面使用安全输入；疑似 URL、查询串或凭证的显示名称在保存和旧配置迁移时替换为安全来源域名；备份和运行配置不含 URL；错误信息不拼接原始链接 |
| 恶意订阅导致明文降级、内存/磁盘耗尽或配置注入 | 仅允许 HTTPS 且重定向不得降级；流式 4 MiB 硬上限；Mihomo 以 proxy-provider 模式验证；YAML 标量转义；最多同时启用 16 个不同节点 |
| 代理控制面或节点端口暴露到局域网 | 固定只绑定 `127.0.0.1:11453–11469`；控制 API 使用 Keychain 随机密钥；端口由 ProjectDock 持久分配；不修改系统代理 |
| 订阅返回登录页、JSON 错误或坏配置，导致节点状态长期悬挂 | 下载后只记录安全格式分类；明确拒绝网页/JSON 错误响应；每个订阅独立发现节点并进入成功或失败终态；失败时停止发现进程、保留上次成功节点且不记录订阅正文 |
| 批量恢复误调用高费用生成模型 | 节点分配与在线复验分离；批量复验只接受用户选中的待验证或已隔离文字模型，并要求费用确认；生成/原生协议模型继续隔离且只能逐个确认验证 |
| 节点测速造成无界外部请求或污染模型健康 | 仅由用户手动触发；固定 HTTPS 204 探针、单节点 5 秒超时、最多并发 6 个；测速结果只保存在进程内，失败不更新模型健康、不恢复路由，也不调用模型接口 |
| 外部代理内核扩大供应链边界 | ModelHub 不下载或捆绑内核，只在用户已安装 Clash Verge/Mihomo 时执行明确候选路径；不读取或修改 Clash Verge 配置与凭证；退出时精确终止自身子进程并删除运行目录 |

## 明确排除

- 不读取或导入其他应用凭证。
- 不监听局域网或公网，不创建隧道或云中继。
- 不修改系统代理、不实施 MITM、不安装根证书。
- 不下载、复制或更新第三方压缩器、代理或辅助二进制；代理订阅功能仅可选执行用户已安装的 Clash Verge/Mihomo 内核，不接管其配置。
