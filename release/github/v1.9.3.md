# ModelHub 1.9.3（build 63）

ModelHub 1.9.3 聚焦代理节点、模型健康恢复、真实协议验证和启动稳定性。应用仍然只在 Mac 本机提供兼容 API，供应商密钥和代理订阅地址保存在 macOS 钥匙串中。

## 主要更新

- 新增 Clash/Mihomo 兼容代理订阅、节点卡片选择、节点搜索和按模型节点分配。
- 节点测速会依次通过被测节点访问固定 HTTPS 外网探针，不测试订阅服务器，也不会调用模型。
- 为文字、图片、视频、音乐、语音、转录、Embedding 和 Rerank 增加真实协议验证与明确的健康活动记录。
- 瞬时 TLS/TUN 错误使用有限重试和供应商熔断，并保留上一轮仍有效的可用状态，避免一次网络波动放大为整批模型隔离。
- 单模型复验不再被无关的供应商目录刷新阻断；参数类错误、限流和权限错误使用更准确的分类。
- 优化启动期间的钥匙串读取和 Widget 快照写入，避免本机 API 已监听但暂时无响应。
- 继续保持严格证书校验、回环监听、凭证脱敏日志和失败关闭的模型目录边界。

## 安装

下载 `ModelHub-1.9.3-macos-universal.dmg`，打开后将 `ModelHub.app` 拖入“应用程序”。本版本同时提供 Universal ZIP 与 SHA-256 校验文件。

正式 DMG 和 App 均使用 Developer ID 签名，并在发布前分别完成 Apple 公证、票据装订、Gatekeeper 与镜像完整性验证。

## 使用边界

- ModelHub 不附带模型额度，第三方模型的价格、权限、地区和账单由对应供应商决定。
- 真实模型测试可能产生供应商费用，只有用户主动确认后才会执行。
- 代理订阅功能要求用户自行安装兼容的 Clash/Mihomo 内核；ModelHub 不下载、不捆绑内核，也不修改系统代理。
- 新发现、未验证、权限不足或真实验证失败的模型继续隔离，不会被强行标记为可用。

## 兼容性

- macOS 14 或更高版本
- Universal：Apple Silicon 与 Intel
