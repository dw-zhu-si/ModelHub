# ModelHub 1.9.0（build 19）

ModelHub 是一款原生 macOS 多模型 API 网关。它把多家 AI 模型服务统一到只监听本机回环地址的 OpenAI 兼容入口，适合开发者、AI 工具作者和本机自动化用户集中管理供应商、凭证、模型、路由、可用性与用量。

## 本版本重点

### 明确隔离所有未验证模型

- 旧版“未测试”记录会在启动、供应商保存、备份导入和恢复时自动迁移为明确的隔离状态。
- 没有健康记录的新模型默认不可路由；只有最近状态明确为 `available` 的模型才会进入直连、路由、MCP、A2A、ACP 和 `/v1/models`。
- “测试全部”每次都重新处理所有已配置模型，包括此前隔离的模型，不再根据缓存状态预先跳过。
- 聊天模型执行真实短文本在线探测；图像、视频、语音、转录、向量、重排及供应商专用模型在未完成对应原生协议验证时保持隔离，不会为了清零状态自动触发可能计费的生成请求。
- 状态界面不再使用含糊的“未测试/跳过”，改为“待验证 · 已隔离”和“需配置/待处理”。
- 本机迁移验证覆盖 466 个模型，结果为 `unknown = 0`；外部目录返回 180 个可用直连模型与 1 条可用路由，逐条确认无隔离目标。

### 11 种语言

- 支持简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、巴西葡萄牙语、俄语和阿拉伯语。
- 主应用可跟随系统语言，也可以在应用内即时切换。
- Widget 跟随 macOS 系统语言。
- 241 个界面字符串已完成全部 11 种语言覆盖，并通过缺失项与格式占位符检查。

### 统一的本机模型入口

- 默认 OpenAI 兼容 Base URL：`http://127.0.0.1:11435/v1`。
- 支持 OpenAI 兼容 Chat Completions 与 Responses API。
- 提供图像、视频、语音、转录、向量和重排等原生端点。
- 可转换 Anthropic Claude 与 Google Gemini 的工具调用、多模态内容和流式响应。
- 对供应商专用能力提供受限制的原生透传入口，保留 HTTP 方法、路径、参数和响应结构。

### 路由、故障隔离与成本保护

- 支持优先级故障转移、轮询、权重随机、最低延迟、最高稳定性、最低成本、最大上下文和综合评分等策略。
- 可根据工具、视觉、音频等能力标签排除不兼容模型。
- 支持并发上限、每分钟限流、熔断、冷却、指数退避和有限回退。
- 不会无条件重放同一次可能计费的请求。

### 可用模型目录

- `/v1/models` 和外部模型目录只返回最近状态明确可用的模型。
- 隔离、不可用、未知、属于已停用供应商或没有可用目标的路由不会暴露给外部调用方。
- 普通外部模型目录读取不会重新访问供应商，也不会再次产生模型测试调用。
- 只有用户主动执行单模型、单供应商或一键测试时，才会重新拉取目录并检测模型。
- 已隔离的聊天模型可在显式测试成功后自动恢复；失败模型继续隔离。

### 用量、预算与本机安全

- 按模型和供应商汇总成功率、延迟、Token、估算费用与上下文节省量。
- 支持手工价格、月度 Token 配额、预算提醒与硬限制；未知价格始终保持未知。
- API Key 与网关令牌保存在 macOS Keychain，配置备份不会包含钥匙串凭证。
- 服务只监听 `127.0.0.1`；日志不记录密钥、提示词或模型响应正文。
- 配置导入提供预览、大小限制与自动回滚副本。

### 原生 macOS 体验

- 默认在菜单栏后台运行，不显示程序坞图标。
- 支持登录时自动启动。
- 桌面 Widget 可显示服务状态、可用模型、供应商、路由、请求量与成功率，不共享密钥或请求正文。
- Universal 构建同时支持 Apple Silicon 与 Intel Mac。
- Widget 扩展使用标准 macOS App Extension 入口，兼容直接分发与 Mac App Store 校验。

## 系统要求

- macOS 14.0 或更高版本。
- Apple Silicon（arm64）或 Intel（x86_64）Mac。
- 使用模型服务需要用户自行准备相应第三方供应商账户、API Key、额度与地区权限；ModelHub 不附带模型额度。

## 安装

1. 下载 `ModelHub-1.9.0-macos-universal.zip`。
2. 解压后把 `ModelHub.app` 移到“应用程序”文件夹。
3. 启动 ModelHub，在“模型供应商”中配置自己的供应商与 API Key。
4. 把现有 OpenAI 客户端的 Base URL 修改为 `http://127.0.0.1:11435/v1`。

本下载包使用 Developer ID 签名，已通过 Apple 公证、票据装订和 Gatekeeper 验证。
