# ModelHub 1.11.0 Beta 1（build 68）

这是移动安全伴侣首个纵向切片的分阶段预发布，不是 iOS App Store 或 Google Play 正式版。

## 新增

- macOS 主应用新增默认关闭、与现有回环 API 分离的 TLS 1.3 移动访问服务。
- 支持两分钟有效且单次使用的二维码配对、Mac 显式批准或拒绝、P-256 设备身份、请求签名、时间戳、nonce、重放防护与设备撤销。
- 新增只读移动概览；不会向移动设备发送供应商密钥、OAuth 令牌、代理订阅 URL、提示词、响应正文或桌面网关令牌。
- 新增 iPhone、iPad、Android 手机和 Android 平板客户端源码。iOS 使用 SwiftUI、Secure Enclave/Keychain 与证书固定；Android 使用 Compose、Android Keystore、证书固定与 Google Code Scanner。
- 新增 Kotlin Multiplatform 共享合同、认证状态机和只读概览客户端。

## 安全边界

- 移动访问默认关闭，现有 `127.0.0.1:11435` API 行为不变。
- 用户必须在 Mac 上显式启用移动访问并批准新设备。
- “忘记设备”会先删除平台私钥，再清除本地绑定；密钥删除失败时失败关闭。
- 只允许 `/mobile/v1` 下的最小化接口，不开放供应商配置、密钥、路由写入或模型调用。

## 当前验证

- Swift 全量测试零失败；一项依赖外部 Mihomo 的验收按设计跳过。
- Android 共享测试、JVM 单元测试、Debug、R8 Release 与 Lint 通过。
- iOS 模拟器通用架构构建和 arm64 设备目标编译通过。
- Android 签名 Release APK 已通过包签名和证书校验。

## 尚未完成

- 真实 iPhone、iPad、Android 手机和 Android 平板的扫码配对与撤销 E2E。
- 真实局域网、VPN、后台恢复、平台硬件密钥属性和无障碍验收。
- iOS App Store 与 Google Play 公开审核和正式上架。
- Windows 桌面端移动配对服务；Windows 1.10.0 不属于本次预发布资产。

本预发布用于内测和收集真机证据。公开商店正式发布将在上述门禁完成后另行决策。
