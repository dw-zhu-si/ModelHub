# ModelHub 1.9.1（build 33）

ModelHub 1.9.1 面向个人开发者和小型团队，集中完成模型目录、路由、价格、治理与本机 Agent 接入的升级。所有常规外部调用仍只读取已经验证可用的本机模型快照，不会隐式重新拉取目录或调用隔离模型。

## 本版本重点

- 新增已有供应商模型目录热更新：严格使用用户保存或官方主机核验过的完整目录 URL，不补全 Base URL；先预览、筛选和增量合并，新模型默认隔离。
- 新增 CSV 模型导入，支持 UTF-8、UTF-16、BOM、Excel 分隔符声明、中英文常见列名、预览与去重，并限制 10 MiB 和最大行数。
- 模型隔离原因细化到缺少凭证、HTTP 状态、协议尚未真实验证、配置问题等；只有 `available` 模型和含可用目标的路由会出现在外部目录。
- 新增供应商机器可读价格一键同步和每日定时更新，支持每模型输入、输出与单次调用费用。首次安装不会为了“补更新”立即访问供应商，下一次设定时间再执行。
- 用量费用支持 USD、CNY、EUR、GBP、JPY、KRW、AUD、CAD 八种显示币种；存储仍以 USD 为基准，汇率使用欧洲央行参考数据。
- 新增工作区、虚拟密钥、模型范围、RPM、预算、到期时间与严格隐私策略；原始虚拟密钥仅显示一次，配置只保存摘要。
- MCP 支持读取用户主动保存的任务上下文，并把文字、图像、视频、语音、向量和重排动作路由到受保护的本机网关；支持 Codex、Claude Desktop 和手动安装。
- 三种不可删除且互斥的同模型默认规则：价格优先、速度优先、官方优先。
- 全面更新原生 SwiftUI 视觉层、状态卡片、隔离原因、进度反馈、暗色模式和 App Store 宣传截图。

## 安全与性能验证

- 145 项自动化测试通过，覆盖路由、隔离、目录、价格、币种、CSV、MCP、Keychain、缓存、HTTP 解析、流式响应和 Widget。
- 依赖树不包含第三方 Swift Package；当前源码和 Git 历史秘密扫描未发现凭证候选。
- 本机 API 仅监听 `127.0.0.1:11435`；并发基准无失败，健康接口 p95 为 6–7 ms，未授权模型目录 p95 为 8–11 ms。
- App、ZIP 和 DMG 均为 Universal（Apple Silicon + Intel）Developer ID 签名；App 与 DMG 已分别通过 Apple 公证、票据装订和 Gatekeeper 校验。

## 系统要求

- macOS 14.0 或更高版本。
- Apple Silicon（arm64）或 Intel（x86_64）Mac。
- 使用模型服务需要用户自己的供应商账户、API Key、余额及地区权限。
