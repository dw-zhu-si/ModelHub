# ModelHub 1.10.0（build 67）

ModelHub 1.10.0 聚焦模型健康恢复、真实可用性验证、节点路由、开发者凭证安全、媒体任务完整性，以及 macOS/Windows 双平台的一致本机网关体验。

> 当前文件是候选发布说明。只有 macOS 公证、Windows 可信 Authenticode 与双架构真机验收、最小真实文字/媒体验证全部通过后，才可用于公开 Release。

## 模型健康与可观测性

- 临时 DNS、断连、超时和 TLS 建连错误只执行一次有界重试，不会因单次网络故障批量隔离上一轮已验证可用的模型。
- 证书不受信任、主机名错误等安全故障继续失败关闭，不会通过禁用 TLS 校验绕过。
- 批量检测先使用供应商普通文本模型作为 canary；供应商级网络故障会暂停该供应商剩余探测并保留已有健康证据。
- 健康状态明确区分可用、待验证且已隔离、不可用、需配置，以及 fresh/stale/never 新鲜度。
- `/health` 提供缓存、代理会话、限流/队列/熔断、幂等、会话亲和、媒体批处理、被动健康和验证新鲜度等有界聚合指标，不暴露提示词、响应或秘密。

## 代理订阅与节点路由

- HTTPS Clash/Mihomo 订阅以节点卡片展示，支持搜索、单节点测速和可见节点批量测速；测速固定访问 HTTPS 204 探针，不调用模型。
- 精确“供应商 + 模型 ID”可以绑定指定节点。Mihomo `select` 组切换必须由回环 Controller 确认后才生效；失败时不保存选择、不测速，也不回退直连。
- 同一个 Mihomo selector 被不同模型并发使用时，节点选择会在上游请求的完整生命周期内受控，避免请求串到错误节点或复用旧隧道。
- Controller 密钥只保存在系统凭证库；订阅 URL 不持久化、不回显，非秘密运行设置可以恢复。

## 开发者凭证池与 OAuth

- 同一供应商可以保存多条开发者 API Key，默认手动选择，只在凭证明确定为撤销或 `invalid_grant` 时故障转移。
- 429、额度不足、网络错误和 5xx 不触发换号，不把多个消费者订阅或账户额度组合成规避供应商限制的通道。
- Gemini Developer OAuth 仅支持用户自有 Google Cloud Desktop OAuth Client 与项目，使用官方端点、固定审查范围、PKCE、state/nonce 和精确回环回调。
- API Key、访问令牌与刷新令牌只存入 macOS Keychain 或 Windows Credential Manager；配置、备份、日志和用量账本只保存非认证元数据。
- ChatGPT、Claude、Gemini Apps 等消费者订阅账号、Cookie、令牌和官方客户端登录文件不会被导入或池化，个人自用也不例外。

## 媒体、可靠性与性能

- 图片、视频、音乐、语音和转录任务只有获得经过校验的 HTTPS 制品 URL 或受限本地制品后才成功；空 2xx 或只有“完成”状态的响应会失败关闭。
- 可计费媒体任务创建不自动重试；异步状态查询有次数、时间和响应大小上限，队列支持暂停、恢复和取消。
- 幂等协调、会话亲和、目标并发、公平排队、响应缓存、用量账本和媒体队列都有明确条目数、字节数、TTL 或并发上限。
- 本机 HTTP 入口采用增量解析，限制请求头、正文、连接数和各阶段超时；上游 I/O 与热路径从 UI 主执行器分离。

## 汇率、默认参考价与用量估算

- ECB 展示汇率在启动时自动补更新，成功后每 6 小时检查；失败时保留上次成功值、30 分钟后重试，并显示生效日、获取时间和最近失败。
- 供应商目录不提供价格时，可为精确识别的模型填入随版本发布的上游公开参考价；来源明确标注“非当前渠道结算价”。
- 手工价、CSV 和供应商机器可读价始终优先；不明确的变体仍保持“未知”，不使用 0 元或不可验证估值冒充费用。

## Windows 客户端

- 新增 Avalonia/.NET Windows 客户端，与 macOS 版共享安全的本机 OpenAI 兼容网关能力。
- 支持 OpenAI、Anthropic、Gemini 与通用兼容协议，以及聊天、Responses、图片、视频、音乐、语音、转录、Embedding 和 Rerank。
- Anthropic/Gemini 无法无损保持的 OpenAI 请求语义会明确返回 400，不会静默丢失工具、结构化输出或采样参数。
- 提供 `win-x64` 与 `win-arm64` 独立更新通道；正式安装包必须使用受信任 Authenticode 签名并完成对应架构 Windows 真机验收。

## 安装与兼容性

- macOS 14 或更高版本；Universal，支持 Apple Silicon 与 Intel。
- Windows x64 与 Windows ARM64 的具体最低版本以完成真机门禁后的正式安装包说明为准。
- 所有正式安装包均应附 SHA-256；macOS 直接分发包必须完成 Developer ID 签名、公证与票据装订，Windows 包必须完成受信任 Authenticode 签名与时间戳。
