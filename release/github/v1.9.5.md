# ModelHub 1.9.5（build 66）

ModelHub 1.9.5 增加受信任发行渠道的应用更新中心，并把“可在运行时刷新的数据”与“必须通过签名发行渠道更新的应用代码”明确分开。

## 主要更新

- 设置页新增“应用更新”，可手动检查新版本，并可由用户选择开启每日一次的自动检查。
- App Store 版只查询 Apple 公开目录，仅接受与 ModelHub 的 App ID 和 Bundle ID 完全匹配的结果，并只打开 App Store 受信任页面。
- GitHub 独立安装版只查询 `dw-zhu-si/ModelHub` 官方最新 Release，拒绝草稿、预发布和非官方主机链接。
- 更新检查使用 12 秒超时、512 KiB 响应上限、HTTPS 与最终主机验证；自动检查默认关闭。
- 模型目录、代理订阅与机器可读价格继续支持无需重启的运行时热更新，并保留来源、同源、容量和隔离校验。
- 应用菜单新增“检查更新…”，更新状态与新版本入口在设置页统一展示。
- 新增安全版本比较、发行渠道解析、返回内容校验和两渠道回归测试。

## 热更新安全边界

- ModelHub 不会下载、替换或执行远程应用代码，也不会从远程脚本改变本机功能。
- App Store 与 GitHub 构建使用独立的发行渠道标记，不会交叉引导用户。
- 热更新新发现的模型仍先保持隔离，必须完成真实协议验证才能进入外部目录与正常路由。
- 更新检查失败只显示可读状态，不影响本机 API 服务，也不改变模型可用性。

## 安装

下载 `ModelHub-1.9.5-macos-universal.dmg`，打开后将 `ModelHub.app` 拖入“应用程序”。同一 Release 还提供 Universal ZIP 与 SHA-256 校验文件。

正式 DMG、ZIP 内的 App 均使用 Developer ID 签名，并在发布前完成 Apple 公证、票据装订、Gatekeeper、双架构和镜像完整性验证。

## 兼容性

- macOS 14 或更高版本
- Universal：Apple Silicon 与 Intel
