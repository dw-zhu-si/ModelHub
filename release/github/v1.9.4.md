# ModelHub 1.9.4（build 65）

ModelHub 1.9.4 聚焦大量模型与高频本机请求下的稳定性、可观察性和运行效率。应用继续只在 Mac 本机提供兼容 API；供应商密钥、代理订阅地址和访问令牌仍由 macOS 钥匙串保护。

## 主要更新

- 为每个“供应商 + 精确模型 ID”增加显式主节点、备选节点顺序和可选自动故障转移；只有连续传输失败或 5xx 达到阈值才会切换，4xx 不误判，候选耗尽后失败关闭。
- 所有普通与流式响应都返回 `X-ModelHub-Request-ID`，便于把客户端请求、缓存命中、上游调用和本机请求日志关联起来。
- `GET /health` 新增缓存、代理会话、限流、熔断和模型验证新鲜度的有界聚合指标，不使用请求 ID 作为高基数标签。
- 本机服务器增加连接数、请求读取、普通处理和流式写入期限，避免失联连接或上游长期占用资源。
- 配置编码与原子写入移出界面主执行器，并使用递增版本阻止晚到的旧快照覆盖新配置。
- 路由延迟/稳定性、权重随机、月度用量和代理端点改用预计算索引或有界热路径，降低大目录与高频请求下的重复扫描和内存放大。
- 完善缓存命中/淘汰、代理会话创建/复用/淘汰、节点切换/耗尽等可观察记录与回归覆盖。
- 千问图片接口新增参考图 `image_url` 到供应商多模态内容的转换，同时保留原生 `input.messages`。

## 安全与行为边界

- 自动代理故障转移默认关闭，只使用用户明确配置的节点，不会静默切换为直连。
- ModelHub 不下载、不捆绑 Clash/Mihomo 内核，也不修改系统代理。
- 服务仍只监听 `127.0.0.1`；日志不记录 API Key、提示词或模型响应正文。
- ModelHub 不附带模型额度。第三方模型的价格、权限、地区和最终账单由对应供应商决定。

## 安装

下载 `ModelHub-1.9.4-macos-universal.dmg`，打开后将 `ModelHub.app` 拖入“应用程序”。同一 Release 还提供 Universal ZIP 与 SHA-256 校验文件。

正式 DMG、ZIP 内的 App 均使用 Developer ID 签名，并在发布前完成 Apple 公证、票据装订、Gatekeeper、双架构和镜像完整性验证。

## 兼容性

- macOS 14 或更高版本
- Universal：Apple Silicon 与 Intel
