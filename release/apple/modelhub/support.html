模型枢纽用户支持

遇到问题时，请先在应用中确认服务状态、供应商启用状态、模型是否可用且未隔离、页面显示的隔离原因，以及客户端 Base URL 是否为 http://127.0.0.1:11435/v1。

提交问题时请提供

  • ModelHub 版本和 macOS 版本。
  • 请求路径、HTTP 状态码和不含密钥/提示词的错误描述。
  • 模型是否处于可用、不可用或隔离状态。
  • 若名录、CSV、价格或汇率更新失败，请提供不含凭证的提示文字与供应商类型。
  • 若应用更新检查失败，请提供发行渠道、当前版本和设置页提示；App Store 版只会打开 App Store，独立版只会打开官方 GitHub Release。

热更新与应用更新

模型目录、代理订阅和价格可以在运行时刷新，但新发现模型仍会保持隔离，完成真实验证后才能参与路由。应用代码不通过远程脚本热替换；请从当前安装渠道获取签名新版本。

请勿发送 API Key、网关令牌、完整提示词或模型响应正文。
