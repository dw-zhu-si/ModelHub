模型枢纽 ModelHub

一款原生 macOS 本机模型 API 网关。统一接入 OpenAI、Claude、Gemini 等多家模型，兼容 Chat 与 Responses API，并支持图像、语音、视频、向量和工具调用。

为开发者和本机自动化提供智能路由、故障转移与模型隔离，模型目录只展示可用模型；密钥由 macOS Keychain 保护，并通过用量分析、后台启动和桌面小组件把日常调用集中到一个安全入口。

  • 密钥保存在 macOS Keychain。
  • 服务仅监听本机回环地址。
  • 支持登录时启动、桌面小组件、用量分析与故障转移。
  • 支持 OpenAI、Anthropic、Gemini 及多种兼容供应商协议。
  • 支持简中、繁中、英、日、韩、西、法、德、巴西葡萄牙语、俄语和阿拉伯语。
