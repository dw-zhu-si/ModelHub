模型枢纽 ModelHub

一款面向个人开发者与小型团队的原生 macOS 本机模型 API 网关。统一接入多家模型服务，兼容 Chat 与 Responses API，并支持图像、语音、视频、向量、重排和工具调用。

ModelHub 提供模型名录热更新、CSV 导入、三项互斥默认路由、故障转移与模型隔离；模型目录只展示完成验证的可用模型。供应商价格可按需或定时同步，费用可用 8 种币种查看。

  • 密钥保存在 macOS Keychain。
  • 服务仅监听本机回环地址。
  • 支持已有供应商热更新模型、CSV 导入和清晰的隔离原因。
  • 支持受信任发行渠道的应用更新检查；不下载或执行远程代码。
  • 支持价格同步、用量预算、8 种展示币种和有界内存缓存。
  • 支持三项互斥默认路由、故障转移、工作区、虚拟密钥和 MCP 安装。
  • 支持登录时启动、菜单栏后台运行与桌面小组件。
  • 支持简中、繁中、英、日、韩、西、法、德、巴西葡萄牙语、俄语和阿拉伯语。
