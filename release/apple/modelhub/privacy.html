模型枢纽隐私政策

生效日期：2026 年 8 月 28 日

本机数据

模型供应商 API Key 和网关令牌保存在 macOS Keychain。配置、模型健康状态和聚合用量默认保存在用户设备上；配置备份不包含 Keychain 凭证。

模型请求

只有用户主动发起调用时，请求内容才会发送到用户选择并配置的第三方模型供应商。第三方如何处理数据受其自身条款和隐私政策约束。

日志与分析

应用不记录 API Key、提示词或模型响应正文。用量分析只保存请求数量、状态、延迟、Token、价格来源和费用估算。价格未知时保持未知。

目录、价格与汇率

只有用户主动操作或启用定时价格更新时，应用才会访问用户配置或内置严格核验的供应商目录。切换非美元展示币种时，应用会从欧洲中央银行固定 HTTPS 地址读取公开参考汇率；保存的是汇率、日期和来源，不发送模型配置、凭证或用量数据。

应用更新检查

用户手动检查更新或明确启用每日检查时，App Store 版会访问 Apple 的公开应用目录，独立安装版会访问本项目的 GitHub 官方 Release API。请求只包含标准网络元数据和当前应用版本，不包含 API Key、模型配置、提示词、响应正文或用量数据。应用只打开受信任发行页面，不下载或执行远程应用代码。

工作区、缓存与 Agent

工作区策略、虚拟密钥摘要和安全审计保存在本机；原始虚拟密钥只显示一次。可选响应缓存默认关闭，仅驻留当前进程内存并按访问范围隔离，不写入磁盘。MCP 与 Agent 接口只接受回环来源和独立令牌。

小组件

小组件只读取服务状态、可用模型数量、供应商、路由、请求量和成功率，不共享密钥、提示词或响应正文。

跟踪与广告

应用不提供广告，不进行跨 App 或跨网站跟踪。
